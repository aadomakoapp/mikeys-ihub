# 👋 Edit the website here

These 3 files control everything on the Mikey's iHub website:

- **`inventory.json`** — products, prices, storage options and product photos
- **`store-info.json`** — phone numbers, WhatsApp, email, address, opening hours, social links
- **`site-text.json`** — headline, categories, customer reviews and other wording

Photos go in the [`public/images`](../public/images) folder.

**Full step-by-step instructions: [HOW-TO-UPDATE.md](../HOW-TO-UPDATE.md)**

Save a change (Commit) and the live site updates itself in about 2 minutes:
